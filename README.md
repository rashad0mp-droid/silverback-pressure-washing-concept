# Silverback Pressure Washing: concept website

Concept preview of a one-page website for Silverback Pressure Washing (Little Elm / Frisco, TX). It is **not** the official business website, and the page carries a `noindex` tag so search engines won't index it.

The hero is an interactive concrete slab that visitors wash clean themselves. Surface textures are generated in code. The one photo (`images/home-evening.jpg`) is from Unsplash, free under the Unsplash License.

Items marked **CONFIRM WITH CLIENT** need the owner's input. The form shows a thank-you message but sends nothing until a handler is connected.
